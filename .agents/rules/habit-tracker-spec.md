# Habit Tracker Design Specification & Color Palette Rules

## Color Palette

### Brand & Accent (Sage Green)
- **Light Mode Accent**: `#4A7C59`
- **Dark Mode Accent**: `#6FA37D`

### Status Colors
- **Done**: `#22A559`
- **Missed**: `#E5484D`
- **Pending**: `#9CA3AF`
- **Skipped**: `#F5A623`

> **STRICT RULE**: Status colors (`done`, `missed`, `pending`, `skipped`) are reserved ONLY for status indicators — they MUST NOT be reused elsewhere in the UI for general buttons, headers, or decorative borders.

### Completion % Thresholds
- **≥ 80%**: `#22A559` (Green)
- **50% – 79%**: `#F5A623` (Amber)
- **< 50%**: `#E5484D` (Red)

### Backgrounds & Surfaces
- **Light Mode Page**: `#FAFAF8`
- **Light Mode Card / Surface**: `#FFFFFF`
- **Dark Mode Page**: `#18181B`
- **Dark Mode Card / Surface**: `#232326`

### Category Tags
*Pastel colors, kept strictly distinct from status colors*
- **Health**: `#5DCAA5`
- **Work**: `#378ADD`
- **Learning**: `#7F77DD`
- **Personal**: `#D85A30`
